# Alternate-page font

Syne variable (600–700), Latin WOFF2 subset. Headings use Bold (700);
links and supporting text use Semibold (600).
Self-hosted via `next/font/local` and scoped to the alternate site's typography.

Sources:

- https://fonts.google.com/specimen/Syne
- https://github.com/google/fonts/tree/main/ofl/syne

The WOFF2 file comes from the Latin subset in the Google Fonts CSS API,
downloaded November 11, 2026. `Syne-OFL.txt` preserves its copyright notices
and SIL Open Font License. Font outlines have not been modified here.
