# Alternate-page fonts

Kumbh Sans variable (600–700), Latin WOFF2 subset. The name uses Bold (700);
links and supporting text use Semibold (600).
Self-hosted via `next/font/local` and scoped to the alternate page.

Sources:

- https://fonts.google.com/specimen/Kumbh+Sans
- https://github.com/google/fonts/tree/main/ofl/kumbhsans

The accompanying OFL file contains the copyright notices and SIL Open Font
License terms for redistribution. Font outlines have not been modified here.

## Font experiments

Sora, Outfit, and Syne are self-hosted variable Latin WOFF2 subsets (600–700).
They are loaded only by `/alternate/type/[font]`, which renders the alternate
site with a comparison toolbar. These routes are excluded from search indexing.
The regular alternate page continues to use Kumbh Sans.

Official sources (downloaded November 11, 2026):

- https://github.com/google/fonts/tree/main/ofl/sora
- https://github.com/google/fonts/tree/main/ofl/outfit
- https://github.com/google/fonts/tree/main/ofl/syne

WOFF2 files come from the Latin subsets in the Google Fonts CSS API. The
matching `*-OFL.txt` files preserve each family's copyright and license.
