# Alternate-page fonts

Cinzel Regular and Cormorant Garamond Regular/Italic, Latin WOFF2 subsets.
Self-hosted via `next/font/local` and scoped to the alternate page.

Sources:

- https://fonts.google.com/specimen/Cinzel
- https://fonts.google.com/specimen/Cormorant+Garamond
- https://github.com/google/fonts/tree/main/ofl/cinzel
- https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

The accompanying OFL files contain the copyright notices and SIL Open Font
License terms for redistribution. Font outlines have not been modified here.
