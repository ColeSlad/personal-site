# Alternate-page fonts

Kumbh Sans variable (600–700), Latin WOFF2 subset. The name uses Bold (700);
links and supporting text use Semibold (600).
Self-hosted via `next/font/local` and scoped to the alternate page.

Sources:

- https://fonts.google.com/specimen/Kumbh+Sans
- https://github.com/google/fonts/tree/main/ofl/kumbhsans

The accompanying OFL file contains the copyright notices and SIL Open Font
License terms for redistribution. Font outlines have not been modified here.
